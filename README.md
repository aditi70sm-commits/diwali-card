# Jagmag Diwali Card

An animated Diwali greeting card that opens with a tap, built as a single HTML file.

Made by Aditi.

## View it

Open the live page: https://aditi70sm-commits.github.io/diwali-card/

## Run it locally

Download `index.html` and open it in any modern browser. No install needed.
